# Raffata Izacky — Portfolio

A focused personal portfolio for **Raffata Izacky Yuargya Aletama**, an Information Systems student at Telkom University preparing for a Semester 4 internship.

## What this portfolio presents

The site documents three academic systems: an E-Commerce Product Management System built with C#/.NET Console, the SiLibrary relational database design built with MySQL, and a Java Campus Cafeteria System. It also includes the verified Google AI Professional Certificate and direct contact details.

## Run locally

```bash
pnpm install
pnpm dev
```

Do not upload credentials, generated build folders, or unrelated course files.

## Technology

React, TypeScript, Vite, Tailwind CSS, and a small set of accessible UI components.
