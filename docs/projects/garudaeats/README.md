# GarudaEats — Campus Cafeteria Ordering System

GarudaEats is an individual Java console assignment for PBO 1. It represents a digital campus-cafeteria ordering flow with menu stock, customer wallet balances, loyalty points, and order states.

| Public artifact | [Source repository](https://github.com/Dex-toxicabyss/garudaeats-campus-ordering-system) |

## What it demonstrates

The project uses four core classes: `MenuItem`, `Customer`, `Order`, and `Kantin`. The brief deliberately excludes inheritance, interfaces, and abstract classes, so the implementation uses private fields, public methods, overloaded constructors, and fixed-size object arrays. It demonstrates a successful payment, insufficient balance, cancellation, and a duplicate-item stock regression check.

## What a reviewer can inspect

The source repository includes five runnable Java files and `README-102042500123.pdf`, the assignment document containing the required identity, system description, class diagram, implementation notes, demo scenario, and reflection.

## Notes

This project is separate from the Week 14 Campus Cafeteria lab because the two briefs require different OOP structures. Keeping them in dedicated repositories lets each project remain faithful to its own grading criteria.
