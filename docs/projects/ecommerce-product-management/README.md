# E-Commerce Product Management System

A console-based product management system created for an Algorithm and Programming course. The project models the product-management side of a small e-commerce workflow using C# and .NET Console.

## What it does

The system supports adding, editing, deleting, and managing product records. Users can search products and filter them by category. Input validation is used to reduce invalid data, while arrays and control-flow structures organize the console application logic.
